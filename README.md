# Data Science Society Booth Display

Looping TV display for the BYU-Idaho Data Science Society booth at the majors and societies fair.

Open `index.html` in a browser and press **F** for fullscreen.

**Controls:** ← → switch slides · space pause · F fullscreen · click the meeting text on the last slide to edit it (saved in that browser).

Meetings: Wednesday nights, 6:00 PM, STC 361 & 367. Just show up and we'll add you to Slack.
